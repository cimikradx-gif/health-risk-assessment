# ระบบลงทะเบียนและประเมินความเสี่ยงสุขภาพเบื้องต้น
## Patient Health Risk Assessment and Registration System

ระบบเว็บแอปพลิเคชันสำหรับลงทะเบียนและประเมินความเสี่ยงด้านสุขภาพเบื้องต้น  
คำนวณค่า BMI และจัดกลุ่มความเสี่ยง 3 ระดับ

### ฟีเจอร์หลัก
- ✅ ตรวจสอบความถูกต้องของข้อมูล (Input Validation)
- 📊 คำนวณค่า BMI และประเมินระดับความเสี่ยง
- 🟢 Low Risk / 🟡 Moderate Risk / 🔴 High Risk
- 💊 คำแนะนำการปฏิบัติตนเฉพาะบุคคล
- 🖨️ พิมพ์รายงานผล

### เทคโนโลยี
- HTML5 / CSS3 / Vanilla JavaScript
- Material Design (Google Fonts + Material Icons)
- Responsive Design (รองรับมือถือ)
